# QuettaGo - Official Landing Page

A highly modern, ultra-responsive landing page for **QuettaGo**, the pioneering multi-service super app based in Quetta, Balochistan, Pakistan. QuettaGo integrates **Food Delivery**, **Express Parcel Pickup & Drop**, and **Safe Ride Booking** in one unified mobile platform.

---

## 🌟 Key Highlights & Features

1. **Ultra-Modern UI/UX**:
   - Built with Tailwind CSS, custom glassmorphism, glowing ambient lighting, and smooth fluid animations.
   - Fully responsive design optimized for Mobile, Tablet, and Ultra-wide Desktop displays.
   - Custom palette tailored to Quetta: Warm Saffron Amber (`#FF5A1F`, `#F59E0B`), Deep Night Sky (`#0B0F17`), and Emerald Green (`#10B981`).

2. **Quetta Cultural Heritage & Landmarks**:
   - **Landmark Highlights**: Hanna Lake & Urak Valley, Serena Chowk, Zarghoon Road, Quetta Cantt, Liaquat Bazaar, and BUITEMS Campus.
   - **Local Food Showcase**: Interactive showcase of Prince Road Balochi Sajji, authentic Namkeen Rosh, winter Landhi, Khadda Kebab, and Quetta Doodh Patti chai.

3. **Interactive Features**:
   - **Interactive Service Switcher**: Quick toggle between Food, Parcel, and Rides in the hero section.
   - **Interactive Quetta Fare & Delivery Time Estimator**: Live client-side calculator computing distance, arrival time, and PKR fare estimates between 9 key Quetta localities.
   - **Culinary Filter**: Filter local favorites by Signature Meats, Winter Classics, and Bazaar Delights.
   - **Mobile Sticky Action Bar**: One-tap installation button fixed at the bottom for mobile visitors.
   - **Google Play App Showcase**: Dedicated rating, downloads, and Play Protect verification card.
   - **Smooth FAQ Accordion**: Expandable answers addressing payment, coverage, safety, and merchant partnerships.

4. **Direct Google Play Integration**:
   - Official Store URL: `https://play.google.com/store/apps/details?id=com.QuettaGo.app`
   - High-conversion badges and buttons located throughout the page.

## 🚀 How to Open & Preview

### Local Preview
Simply double-click `index.html` or open it with any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### With a Local Web Server (Optional)
If you have any web server tool:
```bash
# Using VS Code Live Server extension:
Right-click index.html -> "Open with Live Server"

# Or using Python (if installed):
python -m http.server 8080

# Or using npx serve (if Node.js is installed):
npx serve .
```

## 🌐 Instant Deployment Options

This is a 100% static, client-side project with zero backend dependencies:
- **GitHub Pages**: Push this directory to a GitHub repository, head to `Settings -> Pages`, and select `main` branch.
- **Vercel / Netlify**: Drag and drop the `quettago-landing` folder directly onto the Vercel or Netlify dashboard for instant HTTPS hosting.
